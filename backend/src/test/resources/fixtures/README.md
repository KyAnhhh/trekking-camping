# Dữ liệu kiểm thử

Hồ sơ và tour trong thư mục này đều là dữ liệu giả lập, không dùng để mở bán.
Các test import đọc fixture từ classpath, không phụ thuộc thư mục docs/demo-data.
Ngày của tour được dịch chuyển tương đối trong test để không hết hạn theo thời gian.
Không có tài khoản, mật khẩu, khóa dịch vụ hay dữ liệu khách hàng thật.
